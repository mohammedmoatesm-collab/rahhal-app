# رحّال RAHHAL — نسخة ربط أولية

المشروع مبني على واجهة رحّال العربية، مع ربط أولي بقاعدة Supabase ومشروع Capacitor لتجربة Android.

## الملفات
- `www/index.html`: واجهة الطالب والإدارة.
- `www/app.js`: ربط Supabase، إنشاء الحجز وإلغاؤه، تسجيل دخول الإدارة وعرض الحجوزات.
- `www/logo.svg`: شعار بديل خفيف داخل الحزمة.
- `backend/schema.sql`: الجداول وسياسات RLS.
- `backend/live-functions.sql`: دوال الحجز والإلغاء RPC.
- `.github/workflows/build-android.yml`: محاولة بناء APK تجريبي عبر GitHub Actions.

## قاعدة البيانات
تم إنشاء الجداول وسياسات الوصول ودوال الحجز والإلغاء في مشروع Supabase الذي أنشأه صاحب المشروع. المفتاح الموجود في `www/app.js` هو Publishable فقط، ولا تضع أبدًا `service_role` أو أي Secret داخل ملفات الواجهة.

## ما تعمل عليه النسخة الحالية
- الطالب يستطيع إرسال حجز دون إنشاء حساب، بالاسم ورقم الهاتف.
- اختيار الجامعة والخط ونقطة التجمع وتاريخ الرحلة ومواعيد الذهاب والعودة.
- رمز خاص مخزّن على جهاز الطالب يسمح له بإلغاء حجزه.
- المدير المعتمد يستطيع تسجيل الدخول ومشاهدة الحجوزات وأعدادها حسب اليوم والخط.
- المدير الرئيسي يستطيع إضافة خط جديد وأيام تشغيله ومواعيد الذهاب والعودة ونقاط التجمع والمشرف.
- المدير المعتمد يستطيع رفع أو تغيير صورة الباص لكل خط وتاريخ رحلة بشكل مستقل، والطالب يرى صورة اليوم الذي اختاره.

## إعداد صور الباصات اليومية
1. افتح `backend/daily-bus-photos.sql` وانسخ محتواه إلى SQL Editor في مشروع Supabase ثم نفّذه مرة واحدة.
2. بعد نجاح التنفيذ، افتح لوحة الإدارة وسجّل الدخول كمدير معتمد.
3. من قسم «صورة باص الرحلة» اختر الخط والتاريخ وارفع صورة بصيغة JPG أو PNG أو WEBP بحجم لا يتجاوز 5 ميجابايت.
4. الطالب سيشاهد الصورة المرتبطة بنفس الخط والتاريخ عند اختيارهما. تغيير الصورة لا يغيّر صور تواريخ أخرى.

## حدود مهمة قبل استقبال حجوزات حقيقية
- هذه نسخة أولية وليست إطلاقًا إنتاجيًا.
- واجهة المدير الحالية تدعم إضافة خط جديد؛ لا تدعم بعد تعديل أو حذف الخط الموجود أو إدارة عدة مواعيد مختلفة لنفس اليوم أو إدارة حسابات المديرين من داخل التطبيق.
- يجب اختبار الحجز والإلغاء وتسجيل دخول المدير فعليًا على الويب والهاتف، والتأكد من إعدادات Supabase وRLS.
- لا يوجد حد أقصى للسعة في النسخة الحالية.
- إلغاء الحجز متاح من نفس الجهاز/المتصفح الذي أُنشئ منه الحجز؛ فقدان بيانات المتصفح يعني فقدان رمز الإلغاء.

## تشغيل الواجهة محليًا
يمكن نشر محتويات مجلد `www/` على استضافة مواقع ثابتة تدعم HTTPS. لا تنشر مجلد المشروع كاملًا كموقع.

## بناء Android تجريبي
1. افتح تبويب Actions في المستودع.
2. اختر Build Rahhal Android APK.
3. اضغط Run workflow (أو انتظر تشغيله تلقائيًا بعد أي push).
4. بعد انتهاء ناجح، افتح تفاصيل التشغيل ونزّل Artifact باسم `rahhal-android-debug-apk`.
5. استخرج `app-debug.apk` وثبّته على هاتف Android.

هذا APK تجريبي Debug وغير موقّع للنشر على Google Play. لا تعتبر التطبيق جاهزًا للاستخدام الحقيقي قبل نجاح الاختبار الوظيفي على أجهزة فعلية.
